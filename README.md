# AL ORIYES EXCHANGE v12 – জেদ্দা ক্যাশ কাউন্টার (Bilingual: বাংলা / English)

জেদ্দা ক্যাশ এক্সচেঞ্জ কাউন্টারের জন্য একটি পূর্ণাঙ্গ, দ্বিভাষিক (বাংলা ডিফল্ট ও ইংরেজি টগল), অফলাইন-সক্ষম এবং মোবাইল/ডেস্কটপ ইনস্টলযোগ্য **PWA (Progressive Web App)** সলিউশন।

---

## 🌟 সংস্করণ ১২ (v12)-এ নতুন ফিচারসমূহ:

1. **দ্বিভাষিক ইঞ্জিন (Bilingual: Bangla Default & English Toggle):**
   - **ডিফল্ট ভাষা বাংলা:** অ্যাপটি খুললেই সবকিছু বাংলায় থাকবে।
   - **এক ক্লিকে ইংরেজি:** হেডারে থাকা **`বাং / EN`** বাটনে ক্লিক করলেই সাথে সাথে সম্পূর্ণ ইন্টারফেস (ক্যালকুলেটর, খাতা, টেবিল, রসিদ, নোট কাউন্টার ও পপ-আপ) ইংরেজিতে রূপান্তরিত হবে। আবার ক্লিক করলেই বাংলায় ফিরে আসবে।
   - পছন্দের ভাষাটি ব্রাউজারের মেমোরিতে সেভ থাকবে, তাই পেজ রিলোড দিলেও পরিবর্তন হবে না।
2. **রক-সলিড অফলাইন মোড (Wi-Fi বন্ধ থাকলেও তাত্ক্ষণিক লঞ্চ):**
   - ওয়াইফাই বা ইন্টারনেট সম্পূর্ণ বন্ধ থাকা অবস্থাতেও অ্যাপ ০ সেকেন্ডে ওপেন হবে।
   - স্ক্রিনের উপরে স্বয়ংক্রিয় লাল অফলাইন ব্যানার দেখাবে এবং হেডারের ইন্ডিকেটর লাল হয়ে যাবে।
   - ইন্টারনেট ফিরে এলে স্বয়ংক্রিয়ভাবে ব্যানার চলে যাবে এবং নতুন রেট লোড হবে।

## 📁 প্যাকেজের ভেতরের ফাইলসমূহ:
1. **`index.html`** – মূল ওয়েব অ্যাপ্লিকেশন (বাংলা-ইংরেজি টগল, অফলাইন ডিটেকশন, ক্যালকুলেটর, হিসাব খাতা, নোট কাউন্টার, রসিদ ও ক্লোজিং স্লিপ)।
2. **`manifest.json`** – ওয়েব অ্যাপ ম্যানিফেস্ট (মোবাইল ও পিসিতে অ্যাপ হিসেবে ইনস্টল করার কনফিগারেশন)।
3. **`sw.js`** – সার্ভিস ওয়ার্কার (Cache-First আল্ট্রা-ফাস্ট অফলাইন ক্যাশিং ইঞ্জিন)।
4. **`icon-192.png` & `icon-512.png`** – অ্যাপ আইকন (মোবাইল হোমস্ক্রিন ও ডেস্কটপ টাস্কবারের জন্য)।
5. **`.htaccess`** – অ্যাপাচি সার্ভার কনফিগ (স্বয়ংক্রিয় সিকিউর HTTPS রিডাইরেক্ট)।

## 🌐 InfinityFree হোস্টিংয়ে আপলোড করার নিয়ম:

1. **InfinityFree cPanel / File Manager**-এ যান।
2. **`htdocs`** ফোল্ডারের ভেতরে প্রবেশ করুন।
3. এই ZIP ফাইলটি আনজিপ করে ভেতরের সব ফাইল (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `.htaccess`) সরাসরি **`htdocs`** ফোল্ডারে আপলোড করুন।
4. **ফ্রি SSL চালু করুন:** 
   - InfinityFree ড্যাশবোর্ড থেকে **"Free SSL Certificates"**-এ যান।
   - আপনার ডোমেইনের জন্য ফ্রি SSL রিকোয়েস্ট করে এক ক্লিকে ইনস্টল করে নিন। 
   - SSL চালু হলে সাইটে সবুজ তালা চিহ্ন (HTTPS) আসবে এবং PWA ইনস্টল ফিচার সক্রিয় হবে।

## 📲 কীভাবে অ্যাপ হিসেবে ইনস্টল করবেন?

### ক. অ্যান্ড্রয়েড মোবাইলে:
1. গুগল ক্রোম (Chrome) দিয়ে আপনার সাইটের লিংকে ঢুকুন।
2. হেডারে থাকা **"📲 ইনস্টল"** বাটনে ট্যাপ করুন (অথবা ক্রোমের উপরের ডানপাশের ৩টি ডট `⋮` মেনু থেকে **"Add to Home screen" / "Install App"** সিলেক্ট করুন)।
3. আপনার ফোনের হোমস্ক্রিনে **"Al Oriyes"** নামে অ্যাপটি চলে আসবে।
4. ওপেন করলে ব্রাউজারের কোনো অ্যাড্রেস বার থাকবে না—পুরো আসল অ্যাপের মতো ফুলস্ক্রিনে চলবে এবং **ইন্টারনেট ছাড়াও চলবে**।

### খ. কাউন্টার পিসিতে (Windows / Mac):
1. Chrome বা Edge ব্রাউজারে সাইটটি খুলুন।
2. অ্যাড্রেস বারের ডানপাশে অথবা হেডারের **"📲 ইনস্টল"** বাটনে ক্লিক করুন।
3. আপনার পিসির ডেস্কটপে শর্টকাট চলে আসবে এবং টাস্কবারে পিন করে সফটওয়্যারের মতো চালানো যাবে।

## ⌨️ কাউন্টার কিবোর্ড শর্টকাট (ক্যাশিয়ারদের দ্রুত কাজের জন্য):
- **`Esc`** – যেকোনো খোলা পপ-আপ (রসিদ, কারেন্সি পপ-আপ, নোট কাউন্টার, ক্লোজিং স্লিপ) তাৎক্ষণিক বন্ধ হবে।
- **`Alt + S` বা `F4`** – ক্রয় (Buy) এবং বিক্রয় (Sell) মোড অদলবদল হবে।
- **`F2`** – সরাসরি টাকার পরিমাণ (Amount) লেখার ঘরে কার্সর চলে যাবে।
- **`Ctrl + P`** – কাস্টমার রসিদ ভাউচার ওপেন হবে।

## 📊 দৈনিক ক্লোজিং সামারি স্লিপ (Z-Report):
- প্রতিদিন দোকান বন্ধ করার সময় হিসাব খাতার ডানপাশে থাকা **"📊 ক্লোজিং স্লিপ"** বাটনে ক্লিক করুন।
- এটি স্বয়ংক্রিয়ভাবে আজকের মোট লেনদেনকৃত ভলিউম, মোট ভাউচার সংখ্যা, নিট ক্যাশ লাভ এবং প্রতিটি কারেন্সির আলাদা সারসংক্ষেপ তৈরি করে দেবে।
- **"🖨️ প্রিন্ট করুন"** চাপলে ৮০মিমি থার্মাল প্রিন্টারে ১ পাতার দৈনিক ক্লোজিং রিপোর্ট বের হবে, যা ড্রয়ারের টাকার সাথে মিলিয়ে ফাইলে রাখা যাবে।
